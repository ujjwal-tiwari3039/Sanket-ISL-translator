# Citation and attribution

Sanket ISL Translator has no verified project DOI, publication, tagged release or agreed scholarly author list in the audited checkout. Git commit names establish contribution records but do not establish publication authorship. A `CITATION.cff` is therefore deferred until maintainers confirm the author list and licensing; no identities or release metadata have been invented.

## Cite the software now

In a technical report, identify **Sanket ISL Translator**, link to the [repository](https://github.com/ujjwal-tiwari3039/Sanket-ISL-translator), and record the exact commit SHA and access date you used. Obtain the revision with `git rev-parse HEAD`. Distinguish your own evaluation from the repository's development report.

## Cite the dataset separately

The source dataset publication is [INCLUDE: A Large Scale Dataset for Indian Sign Language Recognition](https://doi.org/10.1145/3394171.3413528). Refer to the [Zenodo dataset record](https://zenodo.org/records/4010759) for creator metadata and licensing. Its DOI must not be assigned to Sanket.

## Future archival release

After confirming software/model/media rights, authors and a reproducible version, maintainers can archive a real release through Zenodo's GitHub integration. Only add a DOI after an archive actually assigns it. An archive is useful for reproducibility, not a substitute for evidence.
