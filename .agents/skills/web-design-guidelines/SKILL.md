---
name: web-design-guidelines
description: Review or implement UI details such as focus, forms, responsive layout and component states against the project checklist. Not for choosing a new brand direction.
---

Read references/checklist.md and DESIGN.md. Trace the user task, then inspect relevant states in the browser. Check semantics before adding ARIA. Report specific affected controls and observable failures. Fix at the responsible component/style layer. Preserve camera, capture and inference semantics. Verify keyboard use, long content, errors and reduced motion; do not claim full accessibility conformance from a code scan.
