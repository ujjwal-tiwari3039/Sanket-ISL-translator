---
name: visual-qa
description: Inspect rendered frontend quality, contrast, responsive behavior or screenshots after UI changes. Not for unit-test-only or database work.
---

Use a local browser and inspect desktop 1440, tablet 768 and mobile 390/320 widths. Capture before/after images when possible. Review hero, navigation, all sections, footer and live/demo loading/error/form states. Check overflow, alignment, line breaks, contrast, focus, hit targets and motion. Test reduced motion and keyboard navigation. Record viewport, URL, browser and evidence paths in docs/design/qa.md. Measure production asset sizes and browser timing separately; synthetic checks are not physical webcam validation. Fix observed defects, rerender affected views, and state anything not tested.
