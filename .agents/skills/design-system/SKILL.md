Maintain DESIGN.md as the source of truth before introducing shared visual components. Define a compact color, type, spacing, border, radius, shadow, motion and breakpoint system. Map tokens to actual CSS; remove conflicting overrides when practical. Distinguish public editorial surfaces from dark live instrumentation while retaining shared typography and rhythm. Use existing primitives before dependencies. Record deviations and verify at desktop, tablet and mobile. Avoid speculative variants or a large unused component library.
